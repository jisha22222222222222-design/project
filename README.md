# ShopZone eCommerce Demo

A responsive React + React-Bootstrap storefront for a frontend assignment.

## Features
- Responsive navigation
- Product grid with category filters and search
- Add products to cart
- Increase/decrease quantity and remove items
- Cart subtotal
- Responsive mobile layout

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Push this folder to GitHub and import the repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

This is a frontend demo. It does not process payments or persist the cart after refresh.
